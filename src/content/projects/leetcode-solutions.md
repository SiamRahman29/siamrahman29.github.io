## What it is

A running archive of programming problems I've solved, almost all in Python. The bulk are from LeetCode, with a scattering from contests and other sources. Themed problem sets, including the Blind 75, live in their own folders.

## Why keep it public

Two reasons. First, solving a problem and *being able to re-derive the approach a month later* are different skills, and writing things down is what turns the first into the second. A solved problem I can't re-explain isn't really solved.

Second, an organized solution set is more useful to the next person than a raw dump of accepted submissions. The folder structure is the difference between "here's some code that passes" and "here's a class of problem to work through." It gets updated as I work through more, and it's meant to be genuinely useful to anyone grinding the same problems.
